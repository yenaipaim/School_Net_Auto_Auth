# 校园网自动认证——适配浏览器认证校园网

### School_Net_Auto_Auth——SNAA

当前版本：2.1.0

面向 Windows 10/11 的校园网托盘工具。连接目标 Wi-Fi 且无法访问指定 HTTPS 地址时，应用使用 Playwright[^playwright] 启动系统 Microsoft Edge 的独立校园网配置，自动填写凭据并按首次录制的点击顺序完成认证。

## 2.1 更新要点

- **安装器重做**：四页流程（欢迎 → 安装位置 → 进度 → 完成），左侧整图、右侧信息，支持自定义安装目录；安装器不请求管理员权限，也不再注册开机自启。
- **可停止的安装**：进度页的「停止」会真正取消并回滚——删除暂存目录、还原卸载注册表、清理刚创建的快捷方式，旧版本原样保留。
- **首启提示替代向导**：安装完成后第一次启动会弹一次说明，勾选「下次启动不再提示」才记住；未配置时自动认证、托盘按钮和状态页都有对应的守卫与横幅。
- **网络设置可扫描 Wi-Fi**：目标 Wi-Fi 改为可编辑下拉框，可扫描附近网络，也可以直接手输；认证地址支持一键自动检测。
- **安装包不含学校信息**：目标 Wi-Fi 与认证地址默认留空，由用户首次使用时填写；配置文件升级到 schema 7，校验失败不再把整份配置改名丢弃。
- **桌面快捷方式**：安装时同时创建开始菜单与桌面快捷方式，卸载时一并清理；卸载不再要求程序装在默认目录。

## 2.0 更新要点

- **界面全面重做**：自绘 40px 应用栏 + 可折叠侧栏 + 透明内容区，扁平工业风（零圆角、1px 发丝线、等宽数字），支持深/浅主题、6 个强调色预设、自定义字体与背景图。
- **高 DPI 清晰度修复**：补上 `app.manifest` 的 PerMonitorV2 声明。此前应用按 100% 渲染后被系统整体放大，125%/150% 缩放下文字和图标发虚，现已按真实缩放渲染。
- **联网判定改为系统网络状态**：不再以“某个网站能否打开”作为唯一依据，详见[联网判定](#联网判定)。
- **修复保存设置时误报失败**：保存设置不再受开机启动项注册结果影响。
- **背景图覆盖范围修正**：背景图现在铺满整个窗口并透过卡片、侧栏与应用栏，不再只显示在内容区背景上。
- **侧栏折叠图标居中修正**：收起后只显示图标，且按侧栏中线对齐，悬停底色铺满整条。
- **卸载窗口尺寸与居中修正**：窗口按显示器缩放换算尺寸并居中到工作区，内容不再被裁切。
- **桌面通知重做**：修复卡片底色不绘制、关闭按钮位置异常、窗口尺寸随文本跳变的问题；改用固定宽度 + 内容自适应高度。
- 配置文件升级到 schema 6，旧配置会自动迁移并补齐外观字段。

## 使用流程

视频教程[SANN演示视频_哔哩哔哩_bilibili](https://www.bilibili.com/video/BV12eeg6bEcg/?vd_source=6bd5ae9c5fdcebb1777c3a0dd437f087)

1. 安装并首次启动后，按提示打开「网络设置」：选择或手输校园网 Wi-Fi，填写认证入口（可点「自动检测」），保存后完成一次录制。
2. 账号密码可保存到 Windows 凭据管理器；也可以在专用 Edge 中保存，浏览器自动填充优先。
3. 点击“开始录制”，先按提示选择账号框和密码框，再按真实认证流程完成所有必要点击。
4. 回到软件点击“结束录制”；如有误点，可删除选中步骤或清除后重新录制。
5. 点击“立即认证”进行测试。成功后程序会关闭自动化 Edge，平时驻留系统托盘。

认证期间如果网页要求电话验证或提示在线设备达到上限，程序会先复查联网状态。尚未联网时，右下角通知会显示经过脱敏和截断的网页提示，并保留当前 Edge 页面供处理；程序在 5 分钟后自动重试。点击“立即认证”可以跳过等待并马上重试。连接成功后，桌面右下角会显示成功通知。

## 界面

主界面使用 WinUI 3 自绘外壳：40px 应用栏 + 可折叠侧栏（220 / 60）+ 透明内容区，按「运行状态 / 网络 / 工具 / 外观」分组，包含状态、认证流程、网络设置、高级设置、课程表和通用设置。点击侧栏右上角的箭头可收起为 60px 图标栏，只保留图标与选中指示，把宽度让给内容区。视觉上采用扁平工业风：全局零圆角、1px 发丝线分层、固定字号档位（28 / 14 / 13 / 12 / 11）、等宽数字读数。

应用通过 `app.manifest` 声明 PerMonitorV2 DPI 感知，在 100% / 125% / 150% 缩放下均按真实像素渲染，不再被系统整体位图放大。窗口移动到另一块不同缩放的显示器时会按该显示器重新布局。

「通用设置 → 外观」可切换深/浅主题、6 个强调色预设或自定义 `#RRGGBB`、界面字体（留空用系统字体栈）以及[背景图像](#背景图像)；选择即时生效并写入配置。浅色模式下强调色会自动加深，保证文字对比度。

## 桌面通知

认证结果通过右下角通知卡片提示：连接成功为绿色竖条、需要手动处理为琥珀色竖条，显示 8 秒 / 30 秒后自动关闭，也可以点右上角的 ✕ 立即关闭。

卡片宽度固定为 360 DIP，高度按实际文字量自适应（96 ~ 300 DIP），文字超长时在卡片内部滚动。窗口按显示器缩放换算成物理像素，因此在 100% / 125% / 150% 下观感一致，不会出现文字挤压或按钮跑位。

## 背景图像

在「通用设置 → 外观」选择背景图。图片会被复制到 `%LOCALAPPDATA%\SchoolNetAutoAuth\backgrounds\`（同一时间只保留一张），原文件之后可以随意移动或删除。支持 `.png`、`.jpg`、`.jpeg`、`.bmp`。

背景图铺满整个窗口，标题栏、左侧导航和内容卡片会一起透出，而不是只显示在内容区背景上：

- 设置背景图后，卡片、面板、侧栏等表面降到 78% 不透明度让图片透出；清除背景图后恢复完全不透明，观感与纯色界面一致。
- 图片与文字之间会自动叠一层主背景色遮罩，强度随「透明度」滑块与当前主题联动：图片越实，遮罩越轻；浅色主题比深色主题压得更重，因为白底深字更怕亮背景图。这样在任何透明度下正文都能读。
- 「透明度」滑块控制图片本身的呈现强度：0% 近似纯色界面，100% 是图片最清晰可见的状态。

## 联网判定

判定以 Windows 自身的网络状态为主，HTTP 探测只作为补充，顺序如下：

1. `NetworkInformation.GetInternetConnectionProfile()` 取不到连接配置 → 判定未联网。
2. 系统给出的连通级别不是 `InternetAccess`（本地访问、受限访问或完全无连接）→ 判定未联网。
3. 以上都通过后，再请求一次「联网检测地址」，用于识别“系统以为已联网、实际被劫持到认证页”的校园网典型状态。判定时不跟随重定向：返回非 2xx 状态码（含 302 跳转、511 需要网络认证）或正文内容像登录页，都判为未联网。

三个步骤都通过才算联网。这套判定同时用于状态显示、认证前后校验、重试节流和重放校验，因此界面显示和实际决策始终一致。

联网检测地址必须是 HTTPS；认证入口地址仅用于打开认证页面，不参与连通性判定。

## 课程表

课程表支持手动维护课程和从文件导入。软件会按照“学期开始日期”计算当前周次，并显示选中日期所在周的课程；主视图按 14 节课的节次与时间排列，课程会根据开始、结束时间跨行显示。

### 支持的上传格式

| 格式 | 用途 | 文件要求 |
| --- | --- | --- |
| `.docx` | 导入 Word 课程表 | 文件内需包含原生 Word 表格，表格至少有 2 个星期表头，并包含类似 `第1-2节 (08:00-09:40)` 的节次时间；课程单元格需包含课程名称和类似 `1-16周`、`1-16周(单)` 的周次信息。最大 20 MiB，不支持旧版 `.doc`。 |
| `.xls` / `.xlsx` | 导入 Excel 课程表 | 工作表需包含星期表头和类似 `第1节(08:20-09:00)` 的节次时间；课程单元格需包含课程名称和类似 `1-16周`、`1-16周(单)` 的周次信息。支持旧版 `.xls` 与新版 `.xlsx`，最大 20 MiB。 |
| `.json` | 导入或导出完整课程表 | 推荐使用本软件导出的 JSON 文件，包含学期开始日期及完整课程字段。 |
| `.csv` | 导入或导出课程列表 | 必须包含 `Name`、`Weekday`、`StartTime`、`EndTime`、`FirstWeek`、`LastWeek` 列；可选 `Teacher`、`Location`、`Parity` 列。时间格式为 `HH:mm`，`Weekday` 使用 `Monday` 至 `Sunday`，`Parity` 使用 `All`、`Odd`、`Even`。 |
| `.ics` | 导入或导出日历事件 | 支持标准 `VCALENDAR`/`VEVENT` 事件，课程应包含开始时间、结束时间、课程名称和每周重复规则。导入 ICS 时会根据最早课程日期推算学期开始日期。 |

### 操作方式

1. 在左侧导航中打开“课程表”。
2. 在“学期开始”下拉列表中选择实际开学日期。导入 DOCX、Excel 和 CSV 前应先确认该日期。
3. 点击“导入”，选择 `.docx`、`.xls`、`.xlsx`、`.json`、`.csv` 或 `.ics` 文件。导入会替换当前课程表，确认后才会写入。
4. 使用“查看日期”切换要查看的周次，或点击“今天”回到当前日期；右侧会显示当天课程和下一节课。
5. 点击“新增”手动添加课程，填写课程名称、教师、地点、星期、开始/结束时间、周次和单双周；选中已有课程后可直接修改并点击“保存课程”。
6. 选中课程后点击删除按钮可移除课程。点击“显示周末”可切换周一到周五或完整一周视图。
7. 点击 `JSON`、`CSV` 或 `ICS` 按钮可导出当前课程表，方便备份或导入其他日历软件。

课程表默认保存在 `%LOCALAPPDATA%\SchoolNetAutoAuth\schedules\current.json`，不会上传到云端。

## 隐私

普通配置文件不保存账号或密码。凭据只保存在 Windows 凭据管理器或 Edge 专用配置中；程序默认不生成截图、视频或 Playwright Trace。

运行日志位于 `%LOCALAPPDATA%\SchoolNetAutoAuth\SchoolNetAutoAuth.log`，最大 1 MiB，超限后自动删除最早内容。日志仅记录固定状态和原因码，不记录账号、密码、Cookie、Token 或网页原文。

课程表的导入和导出仅在用户主动选择文件时执行。

背景图像会复制到本机的 `backgrounds` 目录，仅用于本机显示，不做任何上传。

外观与网络设置保存在 `%LOCALAPPDATA%\SchoolNetAutoAuth\settings.json`，包含主题、强调色、字体、背景图路径和网络参数，不含账号密码。配置使用 schema 7：目标 Wi-Fi 与认证地址默认为空，代表「尚未配置」，是合法状态；只有 JSON 无法解析时才会生成 `settings.corrupt-*.json` 备份，校验不通过会保留原文件并在下次保存时覆盖。

安装包只包含程序本身，不内置任何学校的 Wi-Fi 名称或认证地址；安装器只读取本机的 `settings.json` 用于完成页展示，不会写入配置。

## 本地构建

项目使用 .NET 10 LTS、Windows App SDK、CommunityToolkit.Mvvm 和根目录 `NuGet.Config`。构建产物、本地包缓存、编辑器目录和临时文件由根目录 `.gitignore` 排除。发布命令：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\publish.ps1
```

脚本会生成自包含应用，并使用纯 .NET 安装器生成 `artifacts\installer\校园网自动认证-Setup.exe`。安装器是单个 WinForms 窗口的四页流程（欢迎 / 安装位置 / 进度 / 完成），默认写入 `%LOCALAPPDATA%\Programs\SchoolNetAutoAuth`，也可以改到其它本地固定盘；全程不需要管理员权限，安装失败或中途停止会回滚到安装前状态。安装器不再注册开机自启，自启由应用在首次保存有效配置时补上。

## 卸载

可从 Windows“已安装的应用”或开始菜单中的“卸载校园网自动认证”运行主程序内置的卸载入口。卸载会清理开始菜单与桌面快捷方式，并删除真实的安装目录（包括自定义路径）；默认保留账号凭据、录制配置、日志和 Edge 专用登录状态，只有主动勾选“同时删除用户数据”时才会一并清除。安装目录是磁盘根目录、网络位置、移动盘或系统目录时会拒绝自动删除。

卸载窗口会按当前显示器的缩放比例换算尺寸（620 × 470 DIP），并居中到工作区。内容区带有滚动兜底，屏幕较小或系统字体放大时也不会裁掉底部的操作按钮。

[^playwright]: 本项目自动化测试基于 Playwright 技术：[Microsoft Playwright](https://github.com/microsoft/playwright)。
