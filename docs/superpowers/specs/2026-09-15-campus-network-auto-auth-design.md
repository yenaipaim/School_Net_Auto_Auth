# 校园网自动认证软件设计规格

## 1. 项目概述

“校园网自动认证”是一款面向 Windows 10/11 的桌面工具。程序在用户登录 Windows 后自动启动并常驻系统托盘，持续监测指定 Wi-Fi。连接目标 Wi-Fi 且互联网不可用时，程序使用 Microsoft Playwright 控制系统已安装的 Microsoft Edge，完成校园网认证页面的自动操作。

首个目标校园网配置如下：

- 目标 Wi-Fi：`NSU-SDN`，允许用户修改。
- 认证入口：`http://2.2.2.2`，允许用户修改并跟随页面重定向。
- 联网检测地址：`https://www.yuanshen.com`。
- 页面操作顺序：打开认证入口，点击“登录”，再点击用户预先选择的运营商。
- 支持的运营商由首次录制结果决定，设置中允许用户切换已录制的运营商。

## 2. 技术方案

应用采用 .NET 8 WPF 和 Microsoft.Playwright for .NET 开发，以 Windows x64 自包含安装包交付。

Playwright 启动电脑中已安装的 Microsoft Edge，并使用应用专属的持久化用户数据目录。该浏览器仍是系统 Edge，但不会占用或修改用户日常 Edge 的默认配置，也不会与已经运行的日常 Edge 发生配置目录冲突。

应用为单进程程序，通过系统互斥锁阻止重复启动。第二次启动时，已有实例打开设置窗口或显示当前状态。

## 3. 组件划分

### 3.1 应用宿主

负责应用生命周期、单实例控制、依赖装配和后台任务取消。窗口关闭默认隐藏到托盘，只有托盘菜单中的“退出”才结束进程。

### 3.2 NetworkMonitor

读取当前连接的 Wi-Fi SSID，监听 Windows 网络变化，并通过低频轮询补偿遗漏的系统事件。只有 SSID 与设置中的目标值完全匹配时才允许启动认证。

### 3.3 ConnectivityProbe

以带超时的 HTTP 请求访问 `https://www.yuanshen.com`。能够建立有效 HTTPS 连接并获得正常 HTTP 响应即视为互联网可用；重定向到校园网门户、DNS 失败、连接失败或超时均视为未联网。

检测请求不依赖浏览器 Cookie。检测地址、超时时间和检查间隔保存在应用配置中，其中检测地址在高级设置中可修改，以便目标站点不可用时恢复程序功能。

### 3.4 EdgeAutomation

使用 Playwright 的持久化上下文启动 `msedge` 通道，用户数据存放在应用数据目录中的校园网专用位置。自动化窗口允许显示。

认证流程：

1. 打开认证入口并等待页面进入可操作状态。
2. 定位账号和密码输入框，并给 Edge 密码自动填充预留等待时间。
3. 若输入框仍为空，则从 Windows 凭据管理器读取账号密码并填写。
4. 若浏览器与凭据管理器都没有可用凭据，则停止认证并打开设置窗口。
5. 使用录制的定位器点击“登录”。
6. 等待运营商选择界面，点击设置中预选运营商的定位器。
7. 轮询联网检测，成功后关闭自动化 Edge。

达到最大重试次数后保留 Edge 窗口，便于用户手动处理。

### 3.5 ActionRecorder

首次运行向导引导用户在校园网专用 Edge 中依次标记账号框、密码框、登录按钮和运营商按钮。录制器收集元素的可访问角色、名称、标签、稳定属性和文字，并生成候选 Playwright 定位器。

选择定位器时按以下优先级处理：

1. 可访问角色与名称。
2. 表单标签、占位符或稳定测试属性。
3. 稳定的元素文字。
4. 经过唯一性验证的 CSS 定位器。

每个定位器必须在当前页面中唯一匹配，保存前还要执行一次定位测试。录制过程只保存定位规则和流程顺序，不保存输入框内容、密码、Cookie 或网页源码。

完成录制后，向导执行一次测试认证。只有成功访问联网检测地址后，配置才标记为可用。网页改版导致定位器失效时，程序通知用户重新录制。

### 3.6 CredentialStore

通过 Windows 凭据管理器保存应用内配置的账号密码。普通配置文件只保存凭据条目的逻辑名称，不保存账号或密码明文。

凭据使用顺序：

1. Edge 专用配置已经自动填充的账号密码。
2. Windows 凭据管理器中的账号密码。
3. 两处均无凭据时提示用户配置。

设置界面允许保存、替换和删除凭据。界面不会回显完整密码。

### 3.7 Settings

配置采用带版本号的 JSON 文件保存，并进行字段校验和原子写入。配置包含：

- 目标 SSID。
- 认证入口与联网检测地址。
- 预选运营商。
- 页面元素定位器和录制版本。
- 网络检测间隔与超时。
- 认证超时、重试间隔和最大重试次数。
- 开机自启、通知和诊断日志设置。

损坏或不兼容的配置不会启动自动认证，程序会保留备份并提示用户修复。

### 3.8 StartupManager

使用当前用户级别的 Windows 启动项注册应用，启动参数要求程序最小化到托盘。启用或关闭开机自启不需要管理员权限。卸载程序删除对应启动项。

### 3.9 TrayController 与通知

托盘状态包括：等待目标 Wi-Fi、检查网络、正在认证、已联网、需要配置和认证失败。

托盘菜单提供：

- 立即认证。
- 打开设置。
- 重新录制。
- 查看诊断日志。
- 退出。

“立即认证”仍然检查目标 SSID 和当前联网状态，不在其他网络中误触发门户操作。只有需要用户处理、认证失败或配置失效时发送 Windows 系统通知，正常等待状态保持安静。

## 4. 后台状态机

应用使用显式状态机管理认证，避免并发和循环触发：

1. `WaitingForTargetWifi`：未连接目标 Wi-Fi。
2. `CheckingConnectivity`：已连接目标 Wi-Fi，正在检测互联网。
3. `Online`：联网正常，继续监听网络变化。
4. `Authenticating`：互联网不可用，正在运行 Playwright 流程。
5. `WaitingForCredentials`：没有可用凭据，等待用户配置。
6. `RetryDelay`：一次认证失败，等待下一次重试。
7. `ActionRequired`：达到重试上限或配置失效，需要用户处理。

同一时间只允许存在一个认证任务。SSID 断开或切换时取消正在进行的检测、等待和自动化操作，然后返回 `WaitingForTargetWifi`。网络事件需要去抖，防止短时间内重复认证。

## 5. 重试与错误处理

重试间隔和最大次数由用户配置，应用提供保守默认值。每次重试前重新确认目标 SSID 和互联网状态，已经联网则立即停止重试。

错误分为：

- 网络暂时不可用：按配置重试。
- Edge 启动失败：通知用户检查 Edge 安装，达到上限后停止。
- 页面导航超时：按配置重试并保留诊断信息。
- 定位器未匹配或匹配多个元素：停止自动点击并要求重新录制。
- 凭据不存在或读取失败：停止认证并打开凭据设置。
- 用户关闭自动化 Edge：本次任务取消，是否重试由剩余次数决定。
- SSID 变化：立即取消，不计为认证失败。

最终失败后保留 Edge 窗口并发送系统通知，不自动关闭用户可能正在处理的页面。

## 6. 用户界面

设置窗口使用 Windows 原生、紧凑的工具型布局，包含四个标签页：

- 常规：开机自启、目标 SSID、网络检查间隔。
- 认证：入口地址、运营商、凭据管理、重新录制、测试定位和测试认证。
- 重试：重试间隔、最大次数和认证超时。
- 诊断：当前状态、当前 SSID、最近认证结果和脱敏日志。

首次启动向导只展示完成认证所需的步骤。用户完成首次测试认证后，主窗口关闭到托盘。

## 7. 数据与隐私

- 密码只进入 Edge 密码存储或 Windows 凭据管理器。
- 日志不记录账号、密码、Cookie、表单值、请求头或完整网页内容。
- 配置文件不包含秘密信息。
- Playwright 截图、视频和跟踪默认关闭；仅在用户主动启用诊断并确认隐私提示后临时开启。
- 清除应用数据时允许同时删除专用 Edge 配置、定位器、日志和 Windows 凭据条目。

## 8. 安装与升级

交付 Windows x64 自包含 `.exe` 安装包。安装程序创建开始菜单和卸载入口，首次安装默认启用开机自启，用户可在向导或设置中关闭。

应用安装目录只包含程序文件；可变配置、日志和专用 Edge 数据写入当前用户的应用数据目录。升级时保留兼容配置和凭据，配置版本不兼容时先备份再迁移。

## 9. 测试策略

### 9.1 单元测试

使用 xUnit 覆盖：

- 状态机转换和任务取消。
- SSID 匹配和网络事件去抖。
- 联网检测结果分类。
- 重试次数、间隔和中止条件。
- 配置校验、迁移和损坏恢复。
- 凭据存储接口的成功与失败路径。
- 定位器生成、排序和唯一性选择。

### 9.2 集成测试

提供本地模拟认证站点，覆盖：

- 浏览器自动填充与应用填充两条凭据路径。
- 登录后出现运营商选择页面的流程。
- 页面延迟、导航、重定向和超时。
- 元素缺失、重复匹配和页面改版。
- 成功后关闭 Edge，最终失败后保留 Edge。

集成测试使用测试凭据，不接触真实校园网账号。

### 9.3 Windows 验收

在 Windows 10/11 与稳定版 Microsoft Edge 上人工验证：

- 安装、升级与卸载。
- 用户级开机自启和单实例行为。
- 托盘菜单、系统通知和窗口显示。
- Wi-Fi 切换、断开和重新连接。
- 真实 `NSU-SDN` 环境中的首次录制与自动认证。
- Edge 已保存凭据和 Windows 凭据管理器回退流程。

## 10. 验收标准

项目在满足以下条件时视为完成：

1. 程序能够安装在 Windows 10/11，并在用户登录后自动驻留托盘。
2. 非目标 Wi-Fi 环境不启动认证操作。
3. 连接目标 Wi-Fi 且 `https://www.yuanshen.com` 不可访问时自动执行录制的认证流程。
4. Edge 自动填充优先，未自动填充时可从 Windows 凭据管理器填写。
5. 缺少凭据时不会盲目点击，而是提示用户完成配置。
6. 用户能够预选运营商，并按“登录后选择运营商”的顺序执行。
7. 联网成功后自动关闭专用 Edge；最终失败后保留窗口并通知用户。
8. 重试间隔和最大次数可以配置。
9. 页面定位失效时停止危险操作并引导重新录制。
10. 日志和普通配置中不存在账号密码等敏感信息。

## 11. 非目标范围

首个版本不包含：

- macOS 或 Linux 支持。
- 接管用户已经普通启动的日常 Edge 实例。
- Windows 服务或需要管理员权限的系统级后台进程。
- 自动识别运营商或依次尝试所有运营商。
- 云同步、远程控制或多设备账号同步。
- 绕过验证码、多因素认证或校园网安全策略。
